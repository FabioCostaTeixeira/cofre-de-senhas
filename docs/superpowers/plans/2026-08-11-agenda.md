# Agenda — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agenda semanal (seg-dom, blocos de 15min) de agendamento de gravação: cards com cliente/local/estúdio/tipo/status, arrastáveis (mover dia+horário, redimensionar duração), bloqueio de conflito de horário por estúdio, lixeira, auditoria, master-only.

**Architecture:** Uma tabela (`agendamentos`) com 4 FKs (cliente, local, estúdio, categoria de produto). Camada de dados (`lib/db/agenda.ts`) centraliza a checagem de conflito de horário, reusada por criar/editar/mover. A grade semanal é um client component com pointer events nativos (sem lib de drag-and-drop) — um componente puro de posicionamento (`AgendaCard`, pixel a partir de horário) separado da mecânica de arraste (`AgendaClient`), e um modal de formulário (`AgendaFormularioModal`) reusado tanto pra criar quanto editar.

**Tech Stack:** Next.js 15 (App Router), TypeScript strict, Neon Postgres sem ORM (`@neondatabase/serverless`), vitest (projetos `node` e `jsdom`).

**Spec:** [docs/superpowers/specs/2026-08-11-agenda-design.md](../specs/2026-08-11-agenda-design.md)

## Global Constraints

- TypeScript strict. `npx tsc --noEmit` precisa sair limpo ao fim de toda task.
- `npm test` precisa passar inteiro ao fim de toda task. Base atual: **190 testes**.
- Nenhuma dependência de runtime nova (drag-and-drop é pointer events nativos, sem lib). Nenhuma
  variável de ambiente nova.
- Identificadores em português, como no resto do projeto.
- Autorização é reaplicada no servidor (`requireMaster()` em toda rota/action de `/agenda`).
  Esconder item no menu é cosmético.
- Todo `id` de FK recebido em `lib/db/agenda.ts` passa por `assertUuid` antes de entrar numa query
  — évita erro de cast cru do Postgres (lição da revisão final do Local de Gravação: um id
  malformado deve virar 404 controlado, não erro de driver).
- Sem `on delete cascade` em nenhuma das 4 FKs de `agendamentos`. Sem checagem de "em uso" no
  expurgo de cliente/local/estúdio/categoria por causa de agendamento — fora de escopo desta
  rodada (spec, seção 4 e 12); um expurgo desses vai estourar FK crua se houver agendamento
  referenciando, dívida técnica registrada, não corrigir aqui.
- `status = 'cancelado'` nunca conta pra checagem de conflito de horário.
- Colunas `data`/`hora_inicio`/`hora_fim` sempre lidas com `::text` explícito nas queries de
  leitura — o driver pode devolver `date`/`time` em formatos que variam; o cast garante
  `'yyyy-mm-dd'`/`'HH:MM:SS'` (mesmo cuidado já registrado no módulo Produtos pra `numeric`, que lá
  usa `::float8`).
- Não escrever teste que jsdom não consegue verificar de verdade: a mecânica de pointer events
  (arraste de verdade) fica fora da suíte automatizada (mesma regra já registrada nos planos
  anteriores) — só a função pura de posicionamento e a renderização estática são testadas.

```sql
-- locais_gravacao/estudios. status='cancelado' NAO conta pra checagem de conflito
-- de horario (feita em codigo, lib/db/agenda.ts): um agendamento cancelado libera
-- o estudio pra outro, mas continua visivel na grade (vermelho) como historico.
-- Sem on delete cascade nas 4 FKs: apagar cliente/local/estudio/categoria nao deve
-- apagar agendamento nenhum implicitamente (mesma filosofia do resto do projeto).
create table agendamentos (
  id                   uuid primary key default gen_random_uuid(),
  cliente_id           uuid not null references clientes(id),
  local_id             uuid not null references locais_gravacao(id),
  estudio_id           uuid not null references estudios(id),
  categoria_produto_id uuid not null references categorias_produto(id),
  status               text not null check (
    status in ('cancelado', 'agendado', 'pre_agendado', 'gravando', 'concluido')
  ),
  data                 date not null,
  hora_inicio          time not null,
  hora_fim             time not null check (hora_fim > hora_inicio),
  deleted_at           timestamptz,
  created_at           timestamptz not null default now(),
  updated_at           timestamptz not null default now()
);

create index agendamentos_estudio_data_idx on agendamentos (estudio_id, data);
```

```ts
import type { DadosAgendamento, StatusAgendamento } from '@/lib/types';

const STATUS_VALIDOS: StatusAgendamento[] = [
  'cancelado', 'agendado', 'pre_agendado', 'gravando', 'concluido',
];
const DATA_RE = /^\d{4}-\d{2}-\d{2}$/;
const HORA_RE = /^([01]\d|2[0-3]):[0-5]\d$/;

function horaParaMinutos(hora: string): number {
  const [h, m] = hora.split(':').map(Number);
  return h * 60 + m;
}

export function lerDadosAgendamento(fd: FormData): DadosAgendamento | { error: string } {
  const cliente_id = String(fd.get('clienteId') ?? '');
  if (!cliente_id) return { error: 'Escolha o cliente.' };

  const local_id = String(fd.get('localId') ?? '');
  if (!local_id) return { error: 'Escolha o local de gravação.' };

  const estudio_id = String(fd.get('estudioId') ?? '');
  if (!estudio_id) return { error: 'Escolha o estúdio.' };

  const categoria_produto_id = String(fd.get('categoriaId') ?? '');
  if (!categoria_produto_id) return { error: 'Escolha o tipo de gravação.' };

  const status = String(fd.get('status') ?? '');
  if (!STATUS_VALIDOS.includes(status as StatusAgendamento)) return { error: 'Status inválido.' };

  const data = String(fd.get('data') ?? '');
  if (!DATA_RE.test(data)) return { error: 'Informe a data.' };

  const hora_inicio = String(fd.get('horaInicio') ?? '');
  const hora_fim = String(fd.get('horaFim') ?? '');
  if (!HORA_RE.test(hora_inicio) || !HORA_RE.test(hora_fim)) return { error: 'Informe o horário.' };

  if (horaParaMinutos(hora_inicio) % 15 !== 0 || horaParaMinutos(hora_fim) % 15 !== 0) {
    return { error: 'Horário precisa ser múltiplo de 15 minutos.' };
  }
  if (horaParaMinutos(hora_fim) <= horaParaMinutos(hora_inicio)) {
    return { error: 'Horário de fim precisa ser depois do início.' };
  }

  return {
    cliente_id, local_id, estudio_id, categoria_produto_id,
    status: status as StatusAgendamento, data, hora_inicio, hora_fim,
  };
}
```

```ts
import { sql } from '@/lib/db/client';
import { NotFoundError } from '@/lib/authz';
import { assertUuid } from '@/lib/validation';
import type { Agendamento, DadosAgendamento } from '@/lib/types';

export class ConflitoHorarioError extends Error {
  constructor() {
    super('Este estúdio já tem outro agendamento nesse horário.');
  }
}

/**
 * `status = 'cancelado'` nunca conta (spec): um agendamento cancelado libera o
 * estúdio pra outro. `ignorarId` exclui o próprio registro da checagem, usado por
 * update/mover (sem isso, editar um agendamento sem mudar horário "conflitaria"
 * consigo mesmo).
 */
async function existeConflito(
  estudioId: string, data: string, horaInicio: string, horaFim: string, ignorarId: string | null,
): Promise<boolean> {
  const rows = (await sql`
    select 1 from agendamentos
     where estudio_id = ${estudioId} and data = ${data} and status <> 'cancelado'
       and deleted_at is null
       and (${ignorarId}::uuid is null or id <> ${ignorarId})
       and hora_inicio < ${horaFim} and hora_fim > ${horaInicio}
     limit 1`) as unknown[];
  return rows.length > 0;
}

export async function listAgendamentosDaSemana(
  estudioId: string, inicioSemana: string,
): Promise<Agendamento[]> {
  assertUuid(estudioId);
  return (await sql`
    select a.id, a.cliente_id, cl.nome as cliente_nome, a.local_id, a.estudio_id, e.nome as estudio_nome,
           a.categoria_produto_id, cp.nome as categoria_nome, a.status,
           a.data::text as data, a.hora_inicio::text as hora_inicio, a.hora_fim::text as hora_fim,
           a.created_at
      from agendamentos a
      join clientes cl on cl.id = a.cliente_id
      join estudios e on e.id = a.estudio_id
      join categorias_produto cp on cp.id = a.categoria_produto_id
     where a.estudio_id = ${estudioId} and a.deleted_at is null
       and a.data >= ${inicioSemana}::date and a.data < (${inicioSemana}::date + interval '7 days')
     order by a.data, a.hora_inicio`) as Agendamento[];
}

export async function createAgendamento(dados: DadosAgendamento): Promise<string> {
  assertUuid(dados.cliente_id);
  assertUuid(dados.local_id);
  assertUuid(dados.estudio_id);
  assertUuid(dados.categoria_produto_id);

  if (await existeConflito(dados.estudio_id, dados.data, dados.hora_inicio, dados.hora_fim, null)) {
    throw new ConflitoHorarioError();
  }
  const rows = (await sql`
    insert into agendamentos (
      cliente_id, local_id, estudio_id, categoria_produto_id, status, data, hora_inicio, hora_fim)
    values (
      ${dados.cliente_id}, ${dados.local_id}, ${dados.estudio_id}, ${dados.categoria_produto_id},
      ${dados.status}, ${dados.data}, ${dados.hora_inicio}, ${dados.hora_fim})

  return rows[0].id;
}
```

```tsx
'use client';

import type { Agendamento, StatusAgendamento } from '@/lib/types';

/** 1 bloco = 15 minutos = 16px de altura na grade. */
const ALTURA_BLOCO_PX = 16;

const CORES: Record<StatusAgendamento, string> = {
  cancelado: '#ef4444', agendado: '#22c55e', pre_agendado: '#eab308',
  gravando: '#38bdf8', concluido: '#1d4ed8',
};

export const ROTULOS_STATUS: Record<StatusAgendamento, string> = {
  cancelado: 'Cancelado', agendado: 'Agendado', pre_agendado: 'Pré Agendado',
  gravando: 'Gravando', concluido: 'Concluído',
};

function minutosDesdeMeiaNoite(hora: string): number {
  const [h, m] = hora.slice(0, 5).split(':').map(Number);
  return h * 60 + m;
}

/** Posição (`top`) e altura (`height`) em pixels do card dentro da coluna do dia,
 *  a partir de `hora_inicio`/`hora_fim`. */
export function calcularPosicaoCard(horaInicio: string, horaFim: string): { top: number; height: number } {
  const inicioBlocos = minutosDesdeMeiaNoite(horaInicio) / 15;
  const fimBlocos = minutosDesdeMeiaNoite(horaFim) / 15;
  return { top: inicioBlocos * ALTURA_BLOCO_PX, height: (fimBlocos - inicioBlocos) * ALTURA_BLOCO_PX };
}

export function AgendaCard({
  item, onPointerDownMover, onPointerDownRedimensionar, onClick,
}: {
  item: Agendamento;
  onPointerDownMover: (e: React.PointerEvent) => void;
  onPointerDownRedimensionar: (e: React.PointerEvent) => void;
  onClick: () => void;
}) {
  const { top, height } = calcularPosicaoCard(item.hora_inicio, item.hora_fim);
  return (
    <div
      className="absolute left-1 right-1 rounded text-xs text-white overflow-hidden cursor-pointer select-none"
      style={{ top, height, backgroundColor: CORES[item.status] }}
      onPointerDown={onPointerDownMover}
      onClick={onClick}
    >
      <div className="p-1">
        <div className="font-medium truncate">{item.cliente_nome}</div>
        <div className="truncate">{item.estudio_nome} · {item.categoria_nome}</div>
        <div className="truncate">{ROTULOS_STATUS[item.status]}</div>
      </div>
      <div
        className="absolute bottom-0 left-0 right-0 h-1.5 cursor-ns-resize"
        onPointerDown={(e) => { e.stopPropagation(); onPointerDownRedimensionar(e); }}
      />
    </div>
  );
}
```

```tsx
'use client';

import { useRef, useState } from 'react';
import { useRouter } from 'next/navigation';
import { AgendaCard } from '@/components/AgendaCard';
import { AgendaFormularioModal, type AgendaFormState } from '@/components/AgendaFormularioModal';
import type { Agendamento, CategoriaProduto, LocalGravacao, Terceiro } from '@/lib/types';

const ALTURA_BLOCO_PX = 16;
const BLOCOS_POR_DIA = 96; // 24h * 4 blocos de 15min
const DIAS_SEMANA = ['Segunda', 'Terça', 'Quarta', 'Quinta', 'Sexta', 'Sábado', 'Domingo'];

function minutosDesdeMeiaNoite(hora: string): number {
  const [h, m] = hora.slice(0, 5).split(':').map(Number);
  return h * 60 + m;
}

function minutosParaHora(min: number): string {
  const h = Math.floor(min / 60).toString().padStart(2, '0');
  const m = (min % 60).toString().padStart(2, '0');
  return `${h}:${m}`;
}

function somarDias(dataISO: string, dias: number): string {
  const d = new Date(`${dataISO}T00:00:00`);
  d.setDate(d.getDate() + dias);
  return d.toISOString().slice(0, 10);
}

type Acao = (prev: AgendaFormState, fd: FormData) => Promise<AgendaFormState>;
type ArrastoAtivo = { id: string; data: string; horaInicio: string; horaFim: string };

export function AgendaClient({
  itens, clientes, locais, categorias, estudioId, inicioSemana, criar, salvar, apagar, mover,
}: {
  itens: Agendamento[];
  clientes: Terceiro[];
  locais: LocalGravacao[];
  categorias: CategoriaProduto[];
  estudioId: string;
  inicioSemana: string;
  criar: Acao;
  salvar: Acao;
  apagar: (id: string) => Promise<{ error?: string }>;
  mover: (id: string, data: string, horaInicio: string, horaFim: string) => Promise<{ error?: string }>;
}) {
  const router = useRouter();
  const [aberto, setAberto] = useState<Agendamento | 'novo' | null>(null);
  const [erro, setErro] = useState<string | null>(null);
  const [arrastando, setArrastando] = useState<ArrastoAtivo | null>(null);
  const gridRef = useRef<HTMLDivElement>(null);

  const dias = Array.from({ length: 7 }, (_, i) => somarDias(inicioSemana, i));
  const todosEstudios = locais.flatMap((l) => l.estudios.map((e) => ({ id: e.id, rotulo: `${l.nome} — ${e.nome}` })));

  function itensDoDia(dia: string): Agendamento[] {
    return itens
      .filter((i) => (arrastando?.id === i.id ? arrastando.data : i.data) === dia)
      .map((i) => (arrastando?.id === i.id
        ? { ...i, hora_inicio: arrastando.horaInicio, hora_fim: arrastando.horaFim }
        : i));
  }

  function coordenadas(clientX: number, clientY: number): { dia: number; minutos: number } | null {
    const rect = gridRef.current?.getBoundingClientRect();
    if (!rect) return null;
    const larguraColuna = rect.width / 7;
    const dia = Math.max(0, Math.min(6, Math.floor((clientX - rect.left) / larguraColuna)));
    const minutosCru = ((clientY - rect.top) / ALTURA_BLOCO_PX) * 15;
    const minutos = Math.max(0, Math.min(BLOCOS_POR_DIA * 15 - 15, Math.round(minutosCru / 15) * 15));
    return { dia, minutos };
  }

  async function confirmarMovimento(m: ArrastoAtivo) {
    const r = await mover(m.id, m.data, m.horaInicio, m.horaFim);
    if (r.error) setErro(r.error);
    router.refresh();
  }

  function iniciarMover(item: Agendamento) {
    return (e: React.PointerEvent) => {
      e.stopPropagation();
      const duracao = minutosDesdeMeiaNoite(item.hora_fim) - minutosDesdeMeiaNoite(item.hora_inicio);

      function aoMover(ev: PointerEvent) {
        const c = coordenadas(ev.clientX, ev.clientY);
        if (!c) return;
        const inicio = Math.min(c.minutos, BLOCOS_POR_DIA * 15 - duracao);
        setArrastando({
          id: item.id, data: dias[c.dia],
          horaInicio: minutosParaHora(inicio), horaFim: minutosParaHora(inicio + duracao),
        });
      }
      function aoSoltar() {
        document.removeEventListener('pointermove', aoMover);
        document.removeEventListener('pointerup', aoSoltar);
        setArrastando((atual) => {
          if (atual) void confirmarMovimento(atual);
          return null;
        });
      }
      document.addEventListener('pointermove', aoMover);
      document.addEventListener('pointerup', aoSoltar);
    };
  }

  function iniciarRedimensionar(item: Agendamento) {
    return (e: React.PointerEvent) => {
      e.stopPropagation();

      function aoMover(ev: PointerEvent) {
        const c = coordenadas(ev.clientX, ev.clientY);
        if (!c) return;
        const inicio = minutosDesdeMeiaNoite(item.hora_inicio);
        const fim = Math.max(inicio + 15, c.minutos + 15);
        setArrastando({ id: item.id, data: item.data, horaInicio: item.hora_inicio, horaFim: minutosParaHora(fim) });
      }
      function aoSoltar() {
        document.removeEventListener('pointermove', aoMover);
        document.removeEventListener('pointerup', aoSoltar);
        setArrastando((atual) => {
          if (atual) void confirmarMovimento(atual);
          return null;
        });
      }
      document.addEventListener('pointermove', aoMover);
      document.addEventListener('pointerup', aoSoltar);
    };
  }

  function trocarEstudio(id: string) {
    router.push(`/agenda?estudioId=${id}&semana=${inicioSemana}`);
  }

  function trocarSemana(iso: string) {
    router.push(`/agenda?estudioId=${estudioId}&semana=${iso}`);
  }

  return (
    <div className="space-y-4">
      <div className="flex items-center gap-4 flex-wrap">
        <h1 className="text-xl font-semibold">Agenda</h1>
        <select className="input" value={estudioId} onChange={(e) => trocarEstudio(e.target.value)}>
          {todosEstudios.map((e) => <option key={e.id} value={e.id}>{e.rotulo}</option>)}
        </select>
        <button type="button" className="btn" onClick={() => trocarSemana(somarDias(inicioSemana, -7))}>◀ Semana</button>
        <button type="button" className="btn" onClick={() => trocarSemana(somarDias(inicioSemana, 7))}>Semana ▶</button>
        <button type="button" className="btn btn-primary" onClick={() => setAberto('novo')}>Novo agendamento</button>
      </div>
      {erro && <p className="text-sm" style={{ color: 'var(--danger)' }}>{erro}</p>}

      <div className="grid grid-cols-7 gap-1 text-xs text-center" style={{ color: 'var(--text-dim)' }}>
        {dias.map((dia, i) => (
          <div key={dia}>{DIAS_SEMANA[i]} {dia.slice(8, 10)}/{dia.slice(5, 7)}</div>
        ))}
      </div>
      <div className="grid grid-cols-7 gap-1" ref={gridRef} style={{ height: BLOCOS_POR_DIA * ALTURA_BLOCO_PX }}>
        {dias.map((dia) => (
          <div key={dia} className="relative border" style={{ borderColor: 'var(--border)' }}>
            {itensDoDia(dia).map((item) => (
              <AgendaCard
                key={item.id} item={item}
                onPointerDownMover={iniciarMover(item)}
                onPointerDownRedimensionar={iniciarRedimensionar(item)}
                onClick={() => setAberto(item)}
              />
            ))}
          </div>
        ))}
      </div>

      {aberto && (
        <AgendaFormularioModal
          item={aberto === 'novo' ? undefined : aberto}
          clientes={clientes} locais={locais} categorias={categorias}
          criar={criar} salvar={salvar} apagar={apagar}
          onFechar={() => setAberto(null)}
        />
      )}
    </div>
  );
}
```

```ts
  try {

  } catch (err) {
    if (err instanceof ConflitoHorarioError) return { error: err.message };
    throw err;
  }
  await audit({ actorId: actor.id, action: 'create', entityType: 'agendamento', entityId: id });
  revalidatePath(ROTA);
  return { ok: 'Agendamento criado.' };
}

export async function salvarAgendamento(
  _prev: AgendaFormState, formData: FormData,
): Promise<AgendaFormState> {
  const actor = await requireMaster();
  const id = String(formData.get('id') ?? '');
  if (!isUuid(id)) return { error: 'Agendamento não encontrado.' };

  const dados = lerDadosAgendamento(formData);
  if ('error' in dados) return dados;

  try {
    await updateAgendamento(id, dados);
  } catch (err) {
    if (err instanceof ConflitoHorarioError) return { error: err.message };
    throw err;
  }
  await audit({ actorId: actor.id, action: 'update', entityType: 'agendamento', entityId: id });
  revalidatePath(ROTA);
  return { ok: 'Agendamento atualizado.' };
}

export async function apagarAgendamento(id: string): Promise<{ error?: string }> {
  const actor = await requireMaster();
  if (!isUuid(id)) return { error: 'Agendamento não encontrado.' };

  await softDeleteAgendamento(id);
  await audit({ actorId: actor.id, action: 'delete', entityType: 'agendamento', entityId: id });
  revalidatePath(ROTA);
  return {};
}

export async function moverAgendamento(
  id: string, data: string, horaInicio: string, horaFim: string,
): Promise<{ error?: string }> {
  const actor = await requireMaster();
  if (!isUuid(id)) return { error: 'Agendamento não encontrado.' };

  try {
    await moverOuRedimensionar(id, data, horaInicio, horaFim);
  } catch (err) {
    if (err instanceof ConflitoHorarioError) return { error: err.message };
    throw err;
  }
  await audit({ actorId: actor.id, action: 'update', entityType: 'agendamento', entityId: id });
  revalidatePath(ROTA);
  return {};
}
```

```tsx
/** Segunda-feira da semana corrente (fuso do servidor — mesma limitação de
 *  `hoje`/`new Date()` já aceita em outras partes do projeto sem `America/Sao_Paulo`
 *  explícito quando não é dado de auditoria). */
function segundaAtualISO(): string {
  const hoje = new Date();
  const diaSemana = hoje.getDay(); // 0 = domingo
  const offset = diaSemana === 0 ? -6 : 1 - diaSemana;
  hoje.setDate(hoje.getDate() + offset);
  return hoje.toISOString().slice(0, 10);
}
```
